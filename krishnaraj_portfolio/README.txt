KRISHNARAJ PORTFOLIO WEBSITE

FILES
- index.html: website structure
- style.css: design and responsive layout
- script.js: mobile menu, gallery filters and image lightbox
- images/: your images, named img.JPG through img10.JPG, plus profile.png

HOW TO RUN
1. Extract the ZIP file.
2. Open the krishnaraj_portfolio folder in Visual Studio Code.
3. Open index.html in a browser, or use the Live Server extension in VS Code.
4. Keep the images folder beside index.html. Do not rename it unless you also update the image paths.

IMPORTANT: PERSONALISE BEFORE SHARING
Open index.html and search for:
- +91 XXXXX XXXXX -> replace with your phone number
- yourname@example.com -> replace with your email address (update both occurrences)
- @yourinstagram and https://www.instagram.com/ -> replace with your Instagram handle/profile URL
- Your City, India -> replace with your actual city/location
The profile section uses images/profile.png. If that image is not your preferred profile photo, replace images/profile.png with your own image, keeping the same filename.

HOW TO PUBLISH AND SHARE
- Easy option: use Netlify Drop (https://app.netlify.com/drop). Sign in if prompted, then upload the extracted website folder or a ZIP containing index.html, style.css, script.js and the images folder. Follow the service's current instructions to publish.
- Alternative: GitHub Pages (https://pages.github.com/) by uploading the site files to a repository and enabling Pages.
Once published, copy the public website URL and send it by WhatsApp, email, Instagram bio, or your resume.
The website cannot be published automatically from this package; you must complete the hosting steps yourself.
